# 🪐 Exoplanet Analyzer

### AI-Powered Exoplanet Research & Visualization

**Exoplanet Analyzer** — исследовательское и образовательное настольное приложение на Python, предназначенное для изучения экзопланет с использованием астрономических данных NASA, машинного обучения и интерактивной визуализации.

**Автор и разработчик:** Aldiyar I.R  
**Наставник:** Ansar  
**Год:** 2026  
**Статус:** Исследовательский прототип

## 🎯 Проблема

NASA и другие научные организации публикуют большие каталоги экзопланет, содержащие сведения об их массе, радиусе, плотности, температуре, орбитальных характеристиках и родительских звёздах.

Однако начинающим исследователям и школьникам бывает сложно работать с такими данными из-за большого количества параметров, необходимости их интерпретации и недостатка наглядности.

## 💡 Наше решение

Exoplanet Analyzer объединяет несколько инструментов исследования в одном интерфейсе:

- Анализ физических характеристик экзопланет.
- Предварительная классификация с использованием искусственного интеллекта.
- Интерактивный каталог экзопланет NASA.
- Визуализация распределения планет по параметрам.
- Звёздная карта на основе астрономических координат.
- Условная трёхмерная визуализация планет.
- Создание пользовательских заметок.

**Цель проекта** — сделать исследование экзопланет более доступным, интерактивным и понятным для начинающих.

## 🚀 Основные возможности

### 🤖 1. AI-анализ экзопланет

Программа позволяет вводить физические параметры планеты и получать предварительный прогноз её типа.

Для классификации используется алгоритм машинного обучения **Random Forest**.

Система предназначена для образовательного анализа и не заменяет научную интерпретацию наблюдений.

### 🌌 2. Атлас экзопланет NASA

Приложение позволяет изучать экзопланеты из астрономического каталога.

Доступные возможности:

- Поиск планет по названию.
- Просмотр характеристик объектов.
- Анализ зависимости плотности от массы.
- Выбор объектов для более подробного изучения.

### ✨ 3. Интерактивная звёздная карта

Звёздный атлас отображает объекты по астрономическим координатам прямого восхождения (RA) и склонения (Dec).

Пользователь может перемещаться по карте, изменять масштаб и выбирать интересующие объекты.

### 🌍 4. Трёхмерная визуализация

Программа содержит интерактивную 3D-модель планеты с возможностью вращения и масштабирования.

Визуализация помогает представить исследуемый объект, однако **не является фотографией или научно подтверждённой реконструкцией его поверхности**.

### 📝 5. Заметки исследователя

В приложении предусмотрена система заметок, позволяющая фиксировать наблюдения, идеи и результаты анализа.

## 🔬 Научная гипотеза

Одна из исследовательских задач проекта — оценить, насколько средняя плотность экзопланеты информативна для предварительного определения её физического типа.

**Гипотеза:** плотность может быть одним из наиболее информативных параметров при различении каменистых и газовых планет.

При этом высокая плотность не гарантирует каменистый состав: очень массивные газовые гиганты могут иметь высокую среднюю плотность из-за сильного гравитационного сжатия.

Кроме того, при классификации по массе и радиусу важно учитывать, что плотность рассчитывается из этих же параметров. Поэтому высокая точность плотностного критерия сама по себе не доказывает независимую способность определять состав планеты.

## 💻 Установка и запуск

### 1. Установите Python

Рекомендуется Python 3.10 или новее с совместимыми библиотеками.

### 2. Скачайте проект

На GitHub нажмите **Code → Download ZIP** и распакуйте архив.

### 3. Установите зависимости

Откройте терминал в папке проекта и выполните:

```bash
python -m pip install -r requirements.txt
```

### 4. Подготовьте данные NASA

Скачайте CSV-каталог с сайта [NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/) и сохраните его как `world.csv` в папке, которую использует приложение.

Для полного функционала необходимы соответствующие поля каталога, включая массу, радиус, плотность и координаты объектов.

### 5. Запустите программу

```bash
python Exoplanet_Analyzer.py
```
