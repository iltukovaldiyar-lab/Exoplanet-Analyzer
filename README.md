# Exoplanet Analyzer 🪐

**Exoplanet Analyzer** — учебное настольное приложение на Python для изучения экзопланет по данным NASA.

**Автор и разработчик:** Aldiyar I.R  
**Наставник:** Ansar

## Возможности

- Просмотр и анализ данных каталога экзопланет NASA.
- Предварительная AI-классификация планет на основе доступных характеристик.
- Интерактивная звёздная карта и визуализации.
- Условная 3D-визуализация планеты с вращением мышью.
- Заметки для исследований.

> **Важно:** вывод AI — предварительная оценка, а 3D-изображение не является фотографией реальной экзопланеты. Тип планеты нельзя достоверно определить только по плотности.

## Установка и запуск (Windows)

1. Установите Python 3.10+.
2. Скачайте файлы проекта.
3. Установите зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Скачайте CSV с экзопланетами из [NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/) и сохраните как **`world.csv`** в папку `Загрузки` (`Downloads`) или рядом с `Exoplanet_Analyzer.py`. В CSV должен быть столбец `pl_name`; для полного функционала нужны и другие поля NASA (например `pl_bmasse`, `pl_rade`, `pl_dens`, `ra`, `dec`).
5. Запустите:

   ```bash
   python Exoplanet_Analyzer.py
   ```

## Состояние

Исследовательский прототип. Работоспособность зависит от структуры входного CSV и установленного графического окружения. Проверка синтаксиса Python пройдена; полноценное тестирование GUI на Windows здесь не проводилось.

## Источник данных

[NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/). Данные каталога не включены в репозиторий.
